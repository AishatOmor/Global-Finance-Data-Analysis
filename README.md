# Global-Finance-Data-Analysis
This repository contains a Python project analyzing global financial and macroeconomic data. The project includes exploratory data analysis (EDA), clustering of countries, economic health scoring, predictive modeling of stock market changes, and time series analysis.

# Dataset

Dataset includes macroeconomic indicators and stock market index values for multiple countries over time.

# Key columns:
Country – Name of the country
Date – Observation date
Index_Value – Stock market index
Daily_Change_Percent – Daily change in stock index
GDP_Growth_Rate_Percent – GDP growth
Inflation_Rate_Percent – Inflation rate
Unemployment_Rate_Percent – Unemployment rate
Interest_Rate_Percent – Interest rate
Government_Debt_GDP_Percent – Government debt as % of GDP
Exchange_Rate_USD – Local currency to USD exchange rate
Political_Risk_Score – Political risk measure

Download the dataset:Kaggle https://www.kaggle.com/datasets/imaadmahmood/global-finance-and-economic-indicators-dataset-2024
